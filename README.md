# digital-clock
A simple and modern desktop clock application built with Python and Tkinter. Combines a digital clock, alarm system, and stopwatch in one easy-to-use interface.

Features

 Digital Clock

Displays HH:MM:SS with AM/PM.

Updates every second.

 Alarm System

Set alarms with HH:MM:SS + AM/PM.

Automatic colon formatting while typing.

Popup notification when alarm time is reached.

Alarm history available in the history tab.

⏱Stopwatch

Start, Stop, and Reset functions.

Stopwatch history saved in a separate history tab.

History Page

Separate tabs for Alarm History and Stopwatch History.

Reset buttons to clear histories.
